\# ETL-пайплайн для агрегации курсов валют ЦБ РФ



Проект по автоматическому извлечению данных о курсах валют из открытого API Центробанка РФ, их трансформации и загрузке в реляционную базу данных PostgreSQL с использованием паттерна UPSERT.



\## Стек технологий



\*   \*\*Языки:\*\* Python 3.x, SQL (PostgreSQL)

\*   \*\*Библиотеки:\*\* requests, pandas, psycopg2-binary

\*   \*\*Инструменты:\*\* pgAdmin, Git, Windows Task Scheduler



\## Архитектура проекта



\*   `fetch\_cbr.py` — Python-скрипт для извлечения (Extract) и очистки (Transform) данных от API ЦБ РФ.

\*   `sql/` — DDL-схемы базы данных.

&#x20;   \*   `init\_db.sql` — скрипт создания таблицы с ограничением уникальности.



\## Как запустить проект локально



\*(Инструкция будет дополняться по мере разработки)\*

1\. Клонируйте репозиторий: `git clone <ссылка>`

2\. Создайте виртуальное окружение: `python -m venv venv` и активируйте его: `.\\venv\\Scripts\\activate`

3\. Установите зависимости: `pip install requests pandas psycopg2-binary`
